# Ligooo AI

## Render
- Environment: Node
- Build Command: `npm install`
- Start Command: `npm start`
- Root Directory: déjalo VACÍO si `index.html`, `server.js` y `package.json` están en la raíz del repositorio.

## Variable opcional
`OPENAI_API_KEY`

Si no la configuras, Ligooo funciona en modo DEMO y el botón devuelve respuestas de prueba.
Para usar IA real hay que añadir una clave de API.

No pongas la clave de API dentro de `index.html`.
